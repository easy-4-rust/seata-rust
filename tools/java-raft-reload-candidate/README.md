# RAFT 恢复结果观察候选

独立补丁 0003 与已认证 0001/0002 组合，不覆盖原参考或已封存证据。`getSessionReloadCompletedTerm` 是真实异步 reload 成功后的单调任期记录；失败记录分组、任期、异常。它不改变 `isLeader`，不等于服务就绪，也未实现失败领导隔离。

`RaftReloadObservationTest` 在相同测试二进制上验证原 JAR RED 与候选 GREEN。`runtime.py` 运行自有三节点、3 种 seeded 状态、6 次真实选举与3次快照重载；逐次核验 Seata/JRaft 任期、前后领导身份、原记录/分支、锁与复制位置。外挂控制器不替换原存储或复制实现。只读 Python TM 查询保存完整 101/15/21 请求及响应帧，不注册 RM、不发 Begin/Commit/Rollback。

输入包括固定父清单、全部覆盖类、当前源码、编译依赖；结束时再次核验。首次较弱取样运行保留为诊断，不能替代补强后的主证据。原版恢复缺陷、元数据/日志、指标、自然超时业务补偿、额外解锁配置与正式 Rust 仍按各自计划开放。

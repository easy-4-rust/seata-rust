## 已实现的原语义

- JavaString以Arc<[u16]>保留全部码元，包括NUL和孤立代理码元；UTF8仅作可选缓存。
- 原getSequence/getFunction/getMessage映射*_java无损入口，旧UTF8便利接口签名保留。
- JavaThrowable允许toString返回null，原因Arc身份保留；Java完整toString以JavaString返回。
- ColumnMeta的nullable字符串不归一化；primitive初值0/false，动态字段初值null。
- equals保持other字段先调用的方向；同一句柄立即true、null/其他类型false。
- hashCode保持20字段原顺序、Boolean 1231/1237及有符号i32回绕；不使用Rust随机Hash代替。
- toString按原字段顺序保留引号、null字面量及原UTF16；Rust Display非法码元仅用于显式诊断转义。
- 动态Object回调前释放锁，回调后重新读取尾字段，保留原单线程可重入副作用。
- 替换动态字段在锁外释放旧值；Debug只输出句柄身份，避免用户回调锁死。
- YES忽略大小写保留U+017F长s；196608个候选按原JDK17逐项核验，禁止仅ASCII比较。

## 索引与表元数据依赖阶段（实施中）

动态JavaObject的equals/hashCode/toString与JavaThrowable.toString现使用Result传播原回调异常；SQLParsingException.from_java_cause也返回Result，原因格式化失败时保留同一Arc异常。调用这些早期Rust桥接接口的代码需用?处理，不再假定回调永远成功。JavaObjectError保留异常类、nullable UTF16消息和cause，不吞为false、0或null。

共享列表保存原引用、nullable列表／元素、可变长度与固定长度两种源集合行为；动态列比较／文本回调不能在锁内执行，结构修改按原迭代时机检测。IndexType继承的Object身份哈希不是跨JVM稳定数值：普通Rust使用稳定本机身份标记，另提供显式JVM身份上下文评估入口；差分必须记录身份输入，不伪称任意两个运行时的原始hash自然相等。表名大小写受Java默认语言影响，不以ASCII矩阵充当完整Unicode证明。

## 可观察语义与实现约束

- Java nullable String 映射 Option<String>，缺省 null 与空字符串保持区别。
- Java char 映射 u16，保留 UTF-16 单码元，包括孤立代理码元。
- Java 重载构造器映射 new/paired、Default 或 from_cause 等明确入口。
- Java 异常消息与 cause 分别保留，cause 使用 Arc 保留原身份。
- Java RuntimeException 映射 std::error::Error；不引入 panic 或假成功。
- SQLType 迁移全部48个值；它不扩展 seata_at 允许执行的SQL集合。
- SqlMethodExpr 计数为 i32，保留负数；默认单例计数仍为0。
- TableMeta 共享 ColumnMeta 及大小写不敏感有序映射不能简化为独立副本。
- TableMeta 原 equals/hashCode 对 caseSensitive 不一致，须单独审查并显式映射。
- IndexMeta 原 equals 忽略 cardinality；空 indextype 的异常分支不得悄悄修正。

# Pinned V1 heartbeat and merge-envelope runner

Run from the existing Seata-Rust checkout:

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
python tools/java-control-envelopes/run.py
```

The local runner uses the existing pinned Java export under D:, original Java authority under E:, existing Go export/archive/cache on D:, JDK17, Maven and Rust. It installs no tool, initializes no specification system and starts no TC. Development data remains on D:/E:. It audits2122 Java production source/resource/POM files and all original Go `.go`/module checksum files before and after execution.

The runner copies20 owned Java test overlays into their existing paths in the separate Java build, freezing actual input bytes before Maven. It removes only the15 owned generated reports and the new test class, then runs the selected437 tests. All report counts/failures/skips are checked. All20 input/executed source snapshots and hashes are retained; old pinned Spotless formatting differences are explicit. The new control test must match its canonical input exactly, and any ROOT source edit during the build rejects the validation rather than certifying new uncompiled bytes.

Nine actual Java frame records are captured with strict inventory/header/body checks. New fixtures are created once under `tests/fixtures/protocol/v1/control_envelopes`; subsequent runs compare rather than overwrite them. The original29 payloads/six frames are untouched. Original Go Getty code consumes the same capture and verifies three heartbeat byte round-trips.59/60 codecs are absent in the original registry; six merge cases remain an explicitly open diagnostic. The driver never registers substitute Go codecs.

The Rust full suite, Clippy and formatting checks consume the same fresh capture via `SEATA_IT_CONTROL_WIRE_DIR`. This includes typed/nested batch decoding, strict malformed-input rejection, symmetric budgets and single-byte mutations. The public fixture manifest deliberately distinguishes Java-generated capture from complete cross-language certification.

Collector and source-freshness negative gates can run independently:

```powershell
python -m unittest discover -s tools/java-control-envelopes -p test_collect.py -v
```

For a fresh Go checkout, copy `tools/go-control-envelopes/main.go` into a tool directory inside the pinned Go module, then run it with the generated `vectors.json` path. Use the actual module's codec registry and Getty read/writer. The local driver additionally compares the entire pinned Go source closure against the verified original archive.
